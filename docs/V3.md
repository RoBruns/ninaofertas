# Nina V3 (branch `nina-v3`)

Dashboard operacional redesenhado. **Não publica em produção** — só validação local.

## Rodar local

1. Branch: `git checkout nina-v3`
2. Postgres de teste + `alembic upgrade head` (inclui `0019` e `0020_feed_sources`)
3. API: `.\.venv-test\Scripts\python.exe -m api.serve` (ou `venv` oficial)
4. Dashboard: `cd dashboard && npm run dev` → http://localhost:5173
5. Login com usuário seed / admin do tenant
6. Checklist: login → Fontes (ligar Promobit) → Sincronizar → Esteira

Worker: `python -m worker.main` drena espelho/fontes e checa monitores.

## O que há de novo

- Home de decisões (`GET /api/v3/decisions`)
- Ofertas, Esteira, Fontes & Espelho, Radar de cupons, VIP e Monitor de preço
- Visual editorial graphite (Manrope + Bricolage)
- **Fontes BR** (Promobit + RSS): coletor → `mirror_inbox` → bot dispara sozinho
  (freio/nicho). `GET/PATCH/POST /api/v3/sources`, `POST …/sync`. Job a cada 45s.
